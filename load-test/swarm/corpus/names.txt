# Declared display names (phase 14, DESIGN.md section 26).
#
# What a bot types into "what should people call you". Linted as a BENIGN file,
# and that lint is not decoration here: a declared name is refused outright if
# *any* moderation rule fires (D35), unlike a message, which is flagged and
# delivered. A name in this file that trips `social_handle` would mean every
# bot drawing it is refused at `join_queue`, never enters the queue, and spends
# the run as a connected session that does nothing — a quiet hole in the
# population rather than a loud failure.
#
# Short, because MAX_DISPLAY_NAME_LENGTH is 24 and the client shows this in a
# chat header on a phone. No digits in runs of seven or more (the phone rule),
# no `@`, no dots followed by anything that reads as a TLD.
#
# The accented and non-Latin entries are deliberate: a display name travels the
# same path as a message body, so it is worth having names that are not ASCII
# going through validation, Redis, Pub/Sub and the console's renderer.
