# WHY THIS FILE IS LONG, AND WHY IT HAS TO STAY LONG
# ---------------------------------------------------------------------------
# The offline spam query in the report calls a bot a campaign when it sends the
# same line in five or more *distinct* conversations. A rapid turn-taker sends
# twenty to fifty messages a conversation, so with a forty-line corpus it will
# repeat itself into five conversations within a couple of minutes and be
# accused of running a campaign while doing nothing but chatting.
#
# That happened: a `human` run flagged two N6 bots as false positives, and both
# were the query working correctly on a corpus too small to keep a fast talker
# looking like a person. Growing the file does not hide the finding — a long
# enough run will always produce some benign repetition, and real people repeat
# themselves too — it just stops the harness manufacturing it in minutes.
#
# So: adding a persona that talks faster means checking this file is still big
# enough for it. The false-positive count in the spam oracle is the measurement.
